Operating system algorithms, simulated

An operating system shares scarce hardware (the CPU, memory and the disk) between many programs. The algorithms below decide who gets what and when. Pick a topic, enter your own data and compare how each algorithm performs.

CPU scheduling

Only one process runs on a core at a time, so the scheduler picks the next one from the ready queue. Good choices cut waiting and turnaround time; poor ones leave short jobs stuck behind long ones. Covers FCFS, SJF, SRTF, Priority and Round robin with Gantt charts.

Banker’s algorithm

A deadlock avoidance method by Dijkstra. Before granting a resource request, the system checks that it stays in a safe state, meaning some order exists in which every process can still finish. Find the safe sequence and test new requests.

Open simulator

Page replacement

Virtual memory keeps only some pages in physical frames. When a page is missing and every frame is full, the OS must evict one. Compare FIFO, LRU and Optimal by page faults and hit ratio.

Open simulator

Disk scheduling

On a hard disk, moving the head between cylinders (seek time) is the slowest part of an access. The scheduler orders pending requests to cut head movement. Covers FCFS, SSTF, SCAN, C-SCAN, LOOK and C-LOOK.
